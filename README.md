# Python-Lab1-ConditionalStatementss
 Project Description
This project is part of the Introduction to Python Programming course. It focuses on conditional statements and decision-making using `if`, `elif`, and `else`.

 Objectives
- Practice conditional statements in Python.
- Solve problems using logical operators.
- Improve problem-solving and programming skills.

 Tasks

 Task 1: BMI Calculator
Calculate Body Mass Index (BMI) using weight and height, then display the corresponding category.

 Task 2: Chinese Zodiac Calculator
Determine the Chinese Zodiac animal based on the user's birth year.

 Task 3: Birthday Guessing Game
Guess the user's birthday using predefined number sets and the user's answers.

 Technologies Used
- Python 3
- Conditional statements (`if`, `elif`, `else`)
- User input and output
- Arithmetic and logical operations
